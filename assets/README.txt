📁 ASSETS FOLDER — Yahan apni files rakhein
==========================================

1. Apni photo ka naam: photo.jpg  (ya photo.png)
   → Hero section mein automatically dikhegi

2. Apna resume ka naam: resume.pdf
   → "Download Resume" button se download hoga

NOTE: File ka naam exactly yehi rakhna:
  - photo.jpg   ✅
  - resume.pdf  ✅
  - myphoto.jpg ❌ (kaam nahi karega)

Agar alag naam rakhna ho toh index.html mein yeh lines edit karo:
  <img src="assets/photo.jpg" ...>
  <a href="assets/resume.pdf" ...>
